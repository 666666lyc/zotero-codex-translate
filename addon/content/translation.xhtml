Codex 文献翻译

检查运行环境……

首次从官方上游下载完整 Python、依赖、字体和模型，预计约 600～650 MB。仅 Windows x64 开放自动安装；Codex CLI 需单独安装。

先安装 Codex CLI 并运行 codex login。翻译文本会通过 Codex 发送给模型，使用账号相应额度。

高级设置（兼容外部桥接程序）

支持单篇文本 PDF；尽量保留版式、图片和公式。图像内文字保持原样。原文和已有译文均会保留。

就绪

对照视图：左英文、右中文；默认按页联动。右键“取消主视图”可独立浏览，再选择“设为主视图”恢复联动。
