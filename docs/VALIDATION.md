# 验证矩阵（v0.1.0 开发预览）

本版验证平台：Windows x64 / Zotero 9。

v0.1.0 采用已部署的本地 0.1.6 功能基线，统一插件及桥接版本标识后重新构建。下方 0.1.1～0.1.6 是本地开发阶段的历史编号，记录实际测试版本及范围，并非本次公开发行版本。新包不改变翻译调度、BabelDOC 调用或 PDF 处理；没有因重新发布追加模型调用。

## v0.1.0 发布复核

- 业务源码与本地 0.1.6 基线一致；调整插件及桥接版本标识和发布文档。修正本地开发阶段误改的构建依赖版本，恢复原始锁定文件版本、下载地址及完整性摘要，未升级依赖。
- 从锁文件完成官方 npm 安装；TypeScript、正式压缩 XPI 构建及 30 项 Node 测试通过。包内插件、桥接 wheel 元数据与 VERSION 均为 0.1.0，运行环境清单及 wheel 摘要一致。
- npm 生产依赖审计为 0 项告警；含开发构建工具的全量审计报告 23 项（1 low、4 moderate、18 high）。本轮恢复原始锁定版本，未自动升级构建工具。
- 40 项无账号 Python 测试通过；覆盖缓存、批量调度、取消、恢复、官方 API 调用边界及输出文件处理。本次重新发布不调用模型，不更改个人 Zotero 安装或运行任务。

## 0.1.6 首次点击与工具栏样式

- 30 项 Node、40 项 Python 检查通过，TypeScript 与正式压缩 XPI 构建通过。新增 DOM 文档跨包装对象身份、按钮复用、原生 click 重定向、拖动/取消/键盘不重复执行、同标签页共享切换锁、失败解锁与独立标签页测试。
- 在隔离 Zotero 9 中受控复现旧版故障：原生鼠标按下期间触发工具栏重建，旧按钮被替换，松开落到新按钮，click 落到祖先节点而未打开对照。该复现验证了点击丢失机制，不把所有首击问题概括为加载延迟。
- 修复版在同一重建条件下保留按钮节点；Gecko 将 click 重定向到祖先时，由文档级委托恢复标准按钮 click。真实鼠标一次单击即可打开；未在 pointerdown/pointerup 执行命令。另实测选中文字、页码输入框聚焦、中文附件含批注后的一次点击，以及 Enter 退出、空格开启。
- 正式 XPI 安装并重启后的 20 项连接与阅读集成检查通过；最终包另通过 9 项阅读器复测，包含双向连续同步、独立浏览、分别缩放、两侧批注、中文入口、退出位置及禁用清理。
- 实际阅读器中的选中背景、aria-pressed 和外围阴影通过。浅色/深色 DOM 主题及 100%/125%/150% CSS 控件缩放共 6 项样式检查通过，按钮没有相互重叠；该检查没有修改 Windows 系统显示缩放。焦点、悬停和已开启状态分别处理。
- BabelDOC 调用及 PDF 字节处理与 0.1.5 相同，桥接仅更新版本标识来源；本轮未调用翻译模型，不重新生成个人文献译文。
- 本机部署完成：旧 XPI、Roaming 和 Local 启动缓存已备份，插件及实际专用 Python 桥接均为 0.1.6。当前文献真实一次单击成功打开对照并显示选中阴影；182 个资源全部复用，新增资源下载为 0。旧失败任务和既有中文 PDF 的 SHA256 均未变化。

## 验证方法与适用范围

两页真实账号测试与 12 页替代翻译器排版矩阵是不同验证，后者不能证明真实模型的长文翻译质量，也不代表复杂公式或任意论文的排版都已验收。

登录失效、网络中断、额度耗尽使用模拟错误检查分类和恢复逻辑。真实账号测试使用合成文献；复杂论文的译文和排版建议结合原文人工核对。
