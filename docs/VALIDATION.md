## 本机记录：2026-10-21

- 构建：TypeScript 与通用 XPI 构建通过。XPI 不含运行库、字体或模型二进制，仅带约 74 KB 的运行环境安装材料（含约几十 KB 桥接 wheel）；许可证材料另计。
- 自动测试：Node 6 项、Python 桥接/安装/资源 24 项，共 30 项。覆盖协议、缓存、公式占位符、取消与续跑、单任务门控、损坏文件、路径越界、安装重试复用最终路径、失败升级不改当前环境、数据目录迁移指针重建、宿主镜像隔离及资源后台取消。
- 空缓存：`scripts/runtime_smoke.py` 从官方源准备 uv、独立 Python、85 个固定 wheel、182 个完整资源，原生加载、依赖兼容性、桥接 hello 均通过。没有使用系统 Python 来执行安装器；调用脚本的 Python 仅为测试驱动。
- 固定内容大小：uv 15,237,259 字节，Python 22,019,610 字节，wheel 214,154,933 字节，资源 352,451,566 字节，总计 603,863,368 字节，约 603.9 MB。不含 HTTP 元数据、重试或 Codex CLI。资源实际下载计数与锁定清单一致。
- 本机空缓存耗时 534.4 秒（约 8 分 54 秒）。文件长度总计约 1.76 GB，按文件 ID 扣除 NTFS 硬链接重复后约 1.10 GB，未计文件系统元数据和分配单元开销。不同网络、磁盘和旧环境保留数量会改变耗时与空间。
- 实际取消：3 秒后关闭安装输入管道，任务变为 cancelled，当前环境指针保持不变；随后继续安装通过，全部资源下载计数为 0。升级/续装仍重新创建必要环境，旧环境保留。失败重试复用 pending 版本目录，不重命名 venv。
- 真实账号：Codex CLI 0.134.0，通过 ChatGPT 登录与运行时默认模型 gpt-6.1-sol 完成两页合成文献翻译。四项检查通过；查看两页 PNG，中文标题、双栏正文及图注可读，引用编号和英文参考文献保留。未读取个人文献库或令牌。
- 扩展排版：12 页合成文献、真实 BabelDOC 与替代翻译器的 6 项检查通过，覆盖页码与文本、单/双栏、参考文献、栅格图像像素、表格数值及简单独立公式。另查看第 1、2、3、4、12 页渲染图，中文可读，检查范围内未见明显遮挡或裁切，图内英文保持原样。
- Zotero：独立 profile 和资料库；自动安装、设置窗口、许可证与源码入口、源附件建立、JSONL 桥接、实际中文 PDF 导入、重复导入防护、同标签页双附件、同步翻页、独立浏览、分别保存批注、关闭分屏恢复阅读器及插件退出，共 15 项通过。重试复用运行环境但使用新 profile，避免测试插件重复加载。

## 仍需明确区分的范围

两页真实账号测试与 12 页替代翻译器排版矩阵是不同验证，后者不能证明真实模型的长文翻译质量，也不代表复杂公式或任意论文的排版都已验收。

实际账号的登录失效、网络中断、额度耗尽只验证了错误分类/恢复逻辑，未主动退出用户账号、断开整机网络或耗尽额度。完整禁用/卸载、复杂真实论文和跨平台实机仍待专门验收；不宣称已通过。

CI 配置：四平台源码构建与无账号协议测试；Windows 使用与用户相同的安装器从空缓存下载上游，不用预装开发环境代替。CI 是否通过以 GitHub 实际运行记录为准。
