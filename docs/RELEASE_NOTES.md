# v0.1.0 开发预览

在 Zotero 中通过本机 Codex 将英文 PDF 翻译为中文附件，并在同一标签页中英对照阅读。

适用环境：**Windows x64 / Zotero 9**，单篇有文本层的英文 PDF。

## 功能

- 安装后从官方上游自动准备专用 Python、BabelDOC 和完整字体模型，无需手动安装桥接程序。
- 后台全文翻译、段落缓存、批量请求、取消及手动续跑；完成后自动导入中文附件。
- BabelDOC 0.6.4 官方 Python API 和翻译器扩展接入；不替换内部翻译或排版方法，不重排或修补其输出。
- 工具栏直接开启中英对照，两侧双向同步页码及页内相对位置，可切换独立浏览；批注分别保存。
- 工具栏首次点击与重绘处理修复，开启对照后显示选中背景及外围阴影圈。
- 连接、登录与模型检测即时反馈，提供失败详情、重连及环境修复入口。
- 缓存重新排版及既有 PDF 恢复保留旧任务、译文和批注。

## 安装

1. 安装 [Codex CLI](https://github.com/openai/codex)，运行 `codex login` 并选择 ChatGPT 登录。
2. 下载 Release 中的 **zotero-codex-translate-0.1.0.xpi**，在 Zotero「工具 → 插件」中从文件安装并重启。
3. 在「工具 → Codex 文献翻译：连接设置」查看环境准备进度，完成后检测登录与模型。
4. 通过文献右键菜单或阅读器「Codex 全文翻译」启动；点击「Codex 翻译任务」查看进度，已有译文可直接点击「中英对照」。

首次固定下载内容约 **603.9 MB**，不含 Codex CLI、HTTP 元数据和重试流量，建议至少预留 **3 GB**。后续启动复用已校验环境。普通用户只需下载 XPI；源码及清单供开发、审阅和校验使用。

本次以已部署的本地 0.1.6 功能为基线，统一公开版本号为 v0.1.0。已安装较高本地开发版本的测试用户可从文件手动安装；不会自动降级或覆盖本机正在运行的任务。

## 使用范围

默认一个文档、一个模型请求并发。长文耗时取决于段落数量、缓存及模型响应速度；本次发布没有改变并发或承诺提速。扫描件 OCR、批量文献和图片内文字翻译不在首版范围。

PDF 使用 BabelDOC 原生输出，复杂公式、表格和图文排版建议结合原文人工核对。页数无法对应时可单独打开译文。现有本机验证范围及开发阶段历史记录见 [验证矩阵](VALIDATION.md)。
